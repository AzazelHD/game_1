----------------------------------------------------------------
ISOMETRIC TRANSFORMATION FORMULA (TILED)
----------------------------------------------------------------

Standard 2:1 isometric projection. Prefer the engine helpers
`engine/math/MathUtils::tileToIso` / `isoToTile` and
`engine/renderer/Camera::tileToScreen` over hand-rolling this math.

function TileToScreen(x, y):

    tileWidth  = map.tileWidth
    tileHeight = map.tileHeight

    originX = (map.height * tileWidth) / 2

    screenX = ((x - y) * tileWidth)  / 2 + originX
    screenY = ((x + y) * tileHeight) / 2

    return (screenX, screenY)
